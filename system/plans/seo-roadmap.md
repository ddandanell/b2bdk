# SEO Roadmap — Rolling 12 Weeks

*Owner: seo-master · Reviewed monthly · Last updated: 2026-05-14*

This is the 12-week SEO build plan. Each week has one theme, a small set
of deliverables, and the agent owners. Slice it weekly into
`current-sprint.md`.

## North-star metric

**Organic leads per month** (form submits + WhatsApp inbounds + phone calls
tagged `organic`).

Secondary: rank position on the primary keyword of each area A0–A9.

## How to slice this into a sprint

Each Monday, the project-manager pulls the current week's items into
`current-sprint.md`, plus any backlog urgent items, capped at 5 ship + 3
research + 3 review.

## How to update this roadmap

- The seo-master proposes updates monthly.
- The user approves.
- Mark archived items `[x]` — don't delete them. They are the audit trail.
